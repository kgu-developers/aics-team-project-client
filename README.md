# AICS Team Project Client

## 서비스 소개

경기대학교 컴퓨터공학과의 **강의 팀 프로젝트를 위한 협업 도구**입니다.

팀장 중심의 LMS 제출 방식에서는 팀원이 프로젝트 진행 상황을 확인하기 어렵고, 교수자도 최종 산출물만으로 개인의 기여를 파악하기 어렵습니다.

팀원 모두가 진행 과정을 공유하고, 교수자는 협업 기록을 바탕으로 참여와 기여를 살펴볼 수 있도록 돕습니다. 학기마다 반복되는 강의 개설과 운영 준비를 자동화해 운영 부담도 줄이고자 합니다.
